# What I'm reading

Books that changed how I work, or that I'm working through now.

## Reading now

- **Designing Data-Intensive Applications**, Martin Kleppmann (1st edition). It helped me understand data structures such as B-trees and how databases work underneath.

## Read

- **Exploração de Vulnerabilidades em Redes TCP/IP**, Sandro Melo (in Portuguese). It made the TCP protocol and the way connections are established concrete for me. It also covered probing, which can be as simple as running `nmap` against a host, and how to defend a server's ports. It explained tripwire-style integrity checks too: hashing a server's critical files and commands, so that tampering by an intruder is detected and can trigger a response. Later it helped me troubleshoot a real connection-security problem that I would not have known how to trace otherwise.
